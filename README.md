# Task25
Concatenating DataFrames using Pandas

Description

This project demonstrates how to combine two or more DataFrames vertically and horizontally using the Pandas "concat()" function.

Objective

To learn how to combine datasets with similar or complementary structures.

Tools Used

- Python
- Pandas
- Jupyter Notebook

Concepts Covered

1. Vertical Concatenation: Combining DataFrames row-wise using "axis=0".
2. Horizontal Concatenation: Combining DataFrames column-wise using "axis=1".
3. ignore_index=True: Creates a new continuous index.
4. DataFrame Analysis: Analyzing the combined DataFrame using Pandas functions.

Functions Used

- "pd.concat()"
- "head()"
- "shape"
- "columns"
- "info()"
- "sum()"

Key Learning

Learned how to combine multiple DataFrames, handle indexes, and analyze the resulting dataset using Pandas.

Conclusion

Successfully performed vertical and horizontal concatenation using Pandas and understood how to manage indexes after combining DataFrames.
